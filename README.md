# Social Media Engagement Dashboard

## BCA Capstone Project
This project analyzes social media engagement using Python.

## Objective
To compare the performance of Instagram, Facebook, and YouTube posts using likes, shares, and comments.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Google Colab

## Project Features
- Dataset creation and analysis
- Data inspection
- Correlation analysis
- Platform-wise engagement comparison
- Data visualization
- Interactive dashboard

## Files Included
- Jupyter Notebook (.ipynb)
- Interactive Dashboard (.html)
- Project Report (.pdf)

## Conclusion
This project helps understand social media engagement and compare the performance of different platforms.

**Note:** This project uses sample data for educational purposes.
